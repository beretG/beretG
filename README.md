## 💼 Projekty

### 📊 [Sales Analytics System](https://github.com/beretG/sales-analytics-system) ⭐ **NEWEST**

Kompleksowy system analityczny sprzedaży z zaawansowanymi zapytaniami SQL dla retail analytics.

**Stack:** MS SQL Server 2025, T-SQL, SSMS

**Highlights:**
- 🗄️ **7 znormalizowanych tabel (3NF)** - 400 zamówień, 1,850+ pozycji
- 🎯 **Advanced SQL Techniques:**
  - Common Table Expressions (CTEs) - wielopoziomowe transformacje
  - Window Functions - ROW_NUMBER(), RANK(), NTILE(), LAG(), PERCENT_RANK()
  - Moving Averages (ROWS BETWEEN)
  - Complex CASE logic
- 📈 **Analytical Views:**
  - **Top Products Analysis** - Ranking z percentylami
  - **Monthly Sales Trend** - 3-month moving average, MoM growth
  - **RFM Customer Segmentation** - Champions, At Risk, Lost customers
- ⚡ **Performance Optimization:**
  - Strategic indexing (12 indexes)
  - PERSISTED computed columns
  - Query execution < 100ms
- 📚 **Comprehensive Documentation:**
  - Technical design documentation
  - ERD diagrams
  - Business insights & recommendations

**Business Value:**
- Identifies top 10 products generating 38% of revenue
- Detects customer churn risk before it happens
- Provides actionable insights for inventory & marketing
